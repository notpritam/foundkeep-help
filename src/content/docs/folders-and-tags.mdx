FoundKeep gives you two ways to organize: **folders** and **tags**. They solve
different problems, and you'll usually use both. On top of that, FoundKeep can
suggest tags for you, so you rarely start from a blank page.

## Folders vs. tags

<FoldersVsTags />

<CardGrid>
	<Card title="Folders — where it lives" icon="open-book">
		A save sits in **one** place, the way a file sits in one directory. Reach for
		folders when you think in projects or areas — "Home renovation", "Q3
		planning", "Recipes".
	</Card>
	<Card title="Tags — what it's about" icon="list-format">
		A save can have **many** tags, so the same item shows up under several ideas
		at once. Reach for tags when one save is relevant to more than one thing —
		`pricing`, `saas`, `read-later`.
	</Card>
</CardGrid>

<Aside type="tip" title="Rule of thumb">
**One folder, many tags.** Folders keep the big picture tidy; tags let you slice
across it.
</Aside>

## AI tags vs. your personal tags

FoundKeep keeps two sets of tags side by side:

- <Badge text="AI" variant="success" /> **AI-generated tags** come from
  [AI processing](/privacy/) — FoundKeep reads what you saved and suggests tags
  that describe it. Great for coverage you'd never bother adding by hand.
- <Badge text="Yours" variant="note" /> **Your personal tags** are the ones you
  add yourself. They're yours, and they win — use them for the vocabulary that
  matters to *you*: `read-later`, `client-x`, `buy-later`, `great-writing`.

Both are editable. You can accept an AI tag, remove it, or add your own at any
time. If AI processing is off, you simply have your personal tags.

## How to organize a save

<Steps>

1. Open any save from your [dashboard](https://foundkeep.app/dashboard).
2. Put it in a **folder** (or create a new one).
3. Add **personal tags** for the ideas you'll search by later.
4. Keep, tweak, or clear the **AI tags** as you see fit.

</Steps>

## When to use which

- Keeping a project together, start to finish → **folder**.
- Marking something to come back to → a **tag** like `read-later`.
- The same save matters to two projects → **tags** (it can only live in one folder).
- You want organization without effort → let **AI tags** do the first pass, then
  add a personal tag or two.
